# 前端（Wails 嵌入）

本目录为 **语雀知识库下载器** 的 Svelte + Vite 前端，由 Wails 打包进桌面应用；**不要**单独当公开站点部署使用。

- 开发：在仓库根目录执行 `wails dev`（会拉起本前端 dev server）。  
- 说明与功能列表见上一级 [README.md](../README.md) 与 [USAGE.md](../USAGE.md)。

---

以下为创建工程时自带的 Svelte + Vite 模板说明（仅作参考）。

## Svelte + Vite 模板

[VS Code](https://code.visualstudio.com/) + [Svelte 扩展](https://marketplace.visualstudio.com/items?itemName=svelte.svelte-vscode)。

更多框架能力见 [SvelteKit](https://github.com/sveltejs/kit#readme)。模板选型、HMR 等行为见原 Vite 模板文档。
